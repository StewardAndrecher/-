## 后端复查

要求macOS/Linux、JDK17、Python3，mysql、mysqld、mysqldump、mvn、redis-server在PATH。可用REDIS_SERVER_BIN指定Redis二进制。MySQL需要支持InnoDB和CHECK，当前验收使用9.6.0；不能使用MariaDB替代而不验证兼容性。

```sh
python3 scripts/test_backend.py
```

入口创建全新临时MySQL、明确命名的课程测试库和两个临时Redis，动态分配本机回环端口，不复用真实3306/6379/6380。测试需要清理隔离夹具；不要手动将LESSON*_DB_URL指向业务库。结束停止临时进程，输出位于被忽略的.test-results目录。首次Maven可联网下载；依赖已缓存时可设置MAVEN_OFFLINE=1。

第67/68课覆盖缓存命中/失效/故障降级和Lua限流并发/429/503。第69～73课覆盖订单占用、版本与提交幂等、超时、角色权限、交付/收货、统计快照及操作记录。最新33项包含记录写失败时业务回滚、并发操作不重复记录、历史快照继续推进和一致读取。

## 前端与桌面复查

HBuilderX须安装Vue3 uni-app编译器，Node.js22.12+可用；自定义安装位置设置UNI_COMPILER_HOME为uniapp-cli-vite目录、NODE_BIN为Node可执行文件。

```sh
python3 scripts/test_frontend.py
cd campus-market-desktop
npm ci
npm test
```

前端入口预处理平台分支、重建Web/微信/App资源，执行47组检查及37项工具测试。桌面17项验证静态服务、路径、Host、资源一致性和窗口规则；打包与启动另见启动指南。
