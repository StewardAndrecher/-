## 后端完整集成验证

要求macOS/Linux、JDK17、Python3，mysql、mysqld、mysqldump、mvn在PATH。mysqld必须允许当前非root系统用户建立临时数据目录与本机监听。

```sh
python3 scripts/test_backend.py
```

脚本会创建临时MySQL目录和动态端口，建立各测试场景的独立数据库，验证迁移，清理仓库中生成的旧编译结果后运行41组JUnit类、共504项测试。最后终止自建MySQL并清理自己的临时目录；不连接用户开发数据库。日志在.test-results/backend.log。完整运行通常约10分钟，取决于机器。

首次运行允许Maven下载依赖；已有完整缓存可设置MAVEN_OFFLINE=1。JAVA_HOME由调用者配置为JDK17。直接运行mvn test而没有测试库环境变量时，部分数据库测试会跳过，不能据此声称完整504项验收。

覆盖账号权限、过期会话、参数与文件校验、商品版本/状态、收藏与公开留言、并发幂等、事务回滚、草稿查询、购买意向、双方消息/撤回/阅读游标、未读聚合、排序/接收时间、no-store和健康检查。

## 前端完整检查

要求Node.js22.12+、Python3及HBuilderX编译器。默认采用macOS HBuilderX安装位置，其他位置设置UNI_COMPILER_HOME；可通过NODE_BIN指定Node可执行文件。

```sh
python3 scripts/test_frontend.py
```

入口预处理各平台的模块，重建h5/mp-weixin/app资源，然后运行42组检查和37项工具测试。检查文件在scripts/frontend，临时模块在scripts/.frontend-work，结果在.test-results/frontend.json。模拟状态用于验证账号切换、页面隐藏/销毁、旧响应、读写互斥、失败保留、幂等重试和响应契约；这些模拟检查不能替代手机验收。

三端编译额外检查入口资源、全部12页、组件与样式作用域，以及源码/产物SHA-256清单。当前构建记录为H5 48资源、微信135文件/12页/25作用域、App30资源/12页，编译器版本变化可能改变资源数量。
