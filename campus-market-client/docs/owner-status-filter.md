# 第44课：我的发布按状态筛选

新增软件包和数据库迁移：无。GET /api/products/mine新增可选status，空/不传表示全部，其他仅ON_SALE、OFF_SHELF、SOLD。身份始终从Token取得，不接受sellerId作为授权。状态解析发生在核验登录后，COUNT和分页使用相同的卖家/状态条件，在REPEATABLE_READ只读事务中读取。SQL参数绑定状态值，排序仍按商品ID倒序。

前端静态picker提供全部/在售/已下架/已售出。切换时请求第1页，成功后才提交筛选条件和数据；失败保留旧条件/旧列表及错误提示。返回记录必须属于当前账号且匹配本次请求状态。切换账号清空筛选。最后一页因其他操作缩减时读取最后有效页，最小第1页。

状态操作经服务器确认后，如商品不再匹配当前筛选，先移除该行并调整总数/页码，再GET补齐当前页。补页失败仍保留成功状态操作，并显示列表待刷新，不允许继续写入；手动刷新成功后解锁。写请求超时/5xx/异常响应也要求先刷新确认，不自动重发写请求。409保留原来自动读取最新列表的行为，只重试GET。

测试数据放在独立临时库，真实商品/图片/数据库结构不变；手机验收按用户安排跳过。
