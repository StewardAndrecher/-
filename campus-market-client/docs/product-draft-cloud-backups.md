# 第49课：草稿云端备份
不增加依赖。先保存本机草稿，再手动备份到后端。每个账号最多10份本机草稿、10份云端备份，两个上限独立。
GET /api/product-draft-backups；PUT /api/product-draft-backups/{本机草稿UUID}，请求 {sourceRevision,content}；DELETE 同一路径携带 ?version=云端版本。所有接口需要登录，响应 no-store。
备份并非双向同步：同UUID同来源版本同内容返回原备份，来源版本增加才允许更新，旧来源版本或同版不同内容409。账号行锁配合 FOR UPDATE 当前读防止并发突破10份；普通 COUNT 在 MySQL REPEATABLE READ 中可能读到锁等待前的旧快照。云端载入只填表单，保存时生成新的本机UUID；不会覆盖别的设备本机记录。可重复备份的是持久保存的本机版本，未保存表单不参与请求。
云端版本用于删除冲突保护；删除云端不删本机/商品，发布成功也保留云端/本机草稿。覆盖表单需确认；恢复前再次读取版本。请求失败保留内容并提示刷新；没有自动写入重试。退出/切账号/页面销毁后旧响应不能写回。
价格保持输入字符串，允许尚未完成的输入如12.，备份不等于通过商品发布校验。封面必须属于当前账号。后端部署仍是本机，其他设备需要可访问的后端地址，正式公网部署另课完成。
迁移：备份数据库后执行 server/sql/lesson49-product-draft-backups.sql，仅新增 product_draft_backups，不改既有业务表。
