# 第62课：意向列表本页未读提示

无新增依赖、无数据库迁移。新增GET /api/purchase-intents/message-unread?role=BUYER&intentIds=1,2，登录后读取。最多20个不重复的正安全整数；空集合返回空项、合计0。角色仅BUYER/SELLER，默认BUYER。

每项为intentId、unreadCount，另含role、pageUnreadMessages和pageUnreadIntents。只计算本批次/本页，不是全部历史汇总；结果与输入顺序一致。仅对方未撤回、编号大于当前账号阅读游标的留言计数。无游标视为0，无消息仍返回0。

一条带绑定参数的SQL按当前用户和角色限定意向，LEFT JOIN个人游标与符合条件的消息，GROUP BY意向，避免逐条HTTP/SQL查询。请求非空时只执行一次批量计数SQL（认证另计）。角色列来自封闭枚举，编号只作为绑定参数。任一编号不存在、无权查看或不属于当前角色，整个请求404，不返回部分结果。匿名401、非法条件400，成功与业务错误no-store。

列表先请求原分页，再一次请求当前页未读。两个请求各有快照；不是跨请求的数据库原子快照。两者成功且仍属于当前账号/Token/页面后一起提交。批次失败保留上次列表、分页、统计和未读，标为旧结果；首次失败不显示伪造的0。接受/取消成功后的列表重读也必须取得新批次，失败时明确写入已成功而刷新失败，不重复POST。

每行显示对方未读数或暂无对方未读，本页显示消息数和有未读的意向数。切换角色、筛选、翻页使用新ID集合，空页仍返回0；身份变化清空。第123课起，隐藏/销毁/账号或令牌变化会清空列表、本页未读、总览及筛选并收起组件；详情返回后重新展开，查询最新列表和徽标，旧响应不回填。没有轮询、实时推送、全部历史未读汇总或对方已读回执。打开列表/详情和刷新未读都不会自动标记已读。
