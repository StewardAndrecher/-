# 第60课：撤回自己的私密留言

无新增依赖。迁移给purchase_intent_messages增加is_withdrawn默认false、withdrawn_at可空，以及状态/时间一致性约束。原留言、请求编号、创建时间、主键/外键/唯一键/分页索引保留。

POST /api/purchase-intents/{intentId}/messages/{messageId}/withdraw仅该意向参与者且消息原发送者可用。先从会话取身份、验证正安全整数，再按意向→留言锁顺序核验所属关系。第三人/不存在意向404，跨意向或不存在留言404，同意向另一参与者403，未登录401，非法编号400。发送者可在商品售出后撤回。成功200；首次replayed=false，重复replayed=true且原撤回时间不变。

软删除保留数据库原正文用于原请求幂等校验；不是物理擦除，也不提供恢复显示。接口Message新增withdrawn和withdrawnAt。已撤回时content必须null，正常时正文有效且withdrawnAt=null。GET、撤回响应以及旧发送请求重放均不返回已撤回原文；旧请求同内容返回原已撤回记录，不复活，不同内容仍409。

前端仅本人未撤回留言显示按钮，明确确认后才POST；读、发送、撤回互斥，父页busy事件继续生效。撤回成功先隐藏本行正文，再刷新原页；刷新失败仍保留已确认的撤回占位，不显示旧正文。结果未知需先手动刷新，绝不自动重试。账号/Token/意向/隐藏/销毁/请求序号防止旧确认和旧响应污染。

撤回保留总数、记录编号、创建时间及分页位置，对方需刷新才能看到占位。本课没有实时推送；已看到的内容无法从对方记忆或截图中消除。未确认发送在别处已被撤回时，本页重试只确认原撤回记录并清除待确认草稿。
