# 第61课：私密留言未读数与阅读进度

无新增依赖。新增purchase_intent_message_reads表，每个意向、每个参与者独立一行，记录最后已读留言ID和更新时间。外键保护意向、用户及消息存在性；意向参与者及消息所属意向由服务校验。

GET /api/purchase-intents/{intentId}/messages/read-state返回intentId、lastReadMessageId、latestMessageId、unreadCount。未读仅统计该意向来自另一方、编号大于个人游标且未撤回的留言。自己的消息不计数，撤回占位不计数。无进度为0；查询不会写入、不会自动已读。无对方已读回执。

POST /api/purchase-intents/{intentId}/messages/read，正文{lastMessageId:本次GET的latestMessageId}。身份来自登录会话。先锁所属意向再更新阅读进度，只前进不倒退；重复操作不改更新时间。0为无消息时的幂等空操作；正编号必须属于本意向。第三人/不存在意向404，跨意向/不存在消息404，未登录401，非法请求400。返回最新阅读状态，均no-store。

前端明确手动全部标记已读，会覆盖本次查询时已有的全部留言，并非仅当前页。GET之后新到达的更大编号不被旧POST标记，仍为未读。与发送、撤回共用意向行锁处理竞争，多个设备旧进度不能覆盖新进度。读取状态使用REPEATABLE_READ快照；页面记录和阅读状态为独立GET，在并发变化时各代表自身查询快照。

读、发送、撤回、标记互斥。成功只更新阅读状态，不换页、不清除草稿、不重新发送。未知结果要求刷新，不自动POST；账号/Token/意向/隐藏/销毁及写序号保护旧响应。阅读进度保存在服务端，不把私密正文或进度放本地存储。

本课没有实时推送、首页汇总未读徽标、对方阅读回执。对方新留言需刷新查看，撤回后未读数需刷新更新。
