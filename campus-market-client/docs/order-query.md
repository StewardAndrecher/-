# 第72课：订单筛选与统计页面

我的订单新增七个状态选项，当前角色全部订单的六状态统计，以及已完成模拟交易金额。统计与列表通过一次GET返回。上方统计不受下方筛选、分页影响；外层total才是筛选结果数。金额是完成订单快照的整数分汇总，不代表真实收入或结算。

角色切换保留筛选并回第1页，状态切换回第1页。角色/筛选/页码/列表/统计仅在完整成功后一起提交；失败保留旧快照并标注，首次失败不伪造零。返回订单列表会重新获取，账号切换重置BUYER/ALL/第1页，隐藏/卸载清除私有数据并使旧回调失效。

utils/order.js新增orderFilters、orderSummaryCount、validOrderSummary、formatOrderMoney。api/order.js严格核对响应、统计和、金额、筛选total、页码/行数/状态与重复ID；页面额外验证参与者。统计金额按整数商余格式化。

未新增页面、依赖或数据库迁移；仍沿用14页和原订单状态机。完整代码与截图见第72课文档。
