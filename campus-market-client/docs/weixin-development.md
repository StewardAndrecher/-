# 第29～30课：运行微信小程序与连接诊断

本项目使用同一套 Vue 3 / uni-app 页面运行 Web 与微信小程序。业务接口仍由 Java 后端提供。

## 本机运行

1. 在 IDEA 启动后端，确认 `http://127.0.0.1:8080/api/products` 返回商品分页。
2. 在 HBuilderX 打开 `campus-market-client`。
3. `manifest.json` 的 `mp-weixin.appid` 已填写你提供的微信 AppID。根节点的 `__UNI__...` 是 DCloud AppID，两者不同。
4. HBuilderX 选择“运行 → 运行到小程序模拟器 → 微信开发者工具”。如未识别工具路径，配置已安装的 `/Applications/wechatwebdevtools.app`。
5. 也可以在微信开发者工具中导入 `unpackage/dist/dev/mp-weixin`。应导入编译产物目录，不是 Vue 源码目录。
6. 使用有该 AppID 开发权限的微信账号登录开发者工具；本课只做开发调试，不上传、不发布小程序。

本机微信开发者工具的开发版使用 `http://127.0.0.1:8080`。manifest 中原有 `urlCheck: false` 用于本机开发调试，不能代替正式小程序的合法域名配置。

## 服务器地址

统一配置在 `config/server.js`：普通接口、图片上传、图片展示使用同一地址。配置只接受 origin（协议、主机和可选端口），不要填写 `/api`、用户名密码或查询参数。

| 配置 | 使用场景 |
|---|---|
| web | 本机网页，当前 `http://localhost:8080` |
| weixinDevelop | 微信开发者工具，当前 `http://127.0.0.1:8080` |
| weixinDevice | 开发版手机，当前 `http://192.168.1.100:8080`；电脑换网络后更新此地址 |
| weixinTrial | 体验版，待部署后填写 HTTPS 域名 |
| weixinRelease | 正式版，待部署后填写 HTTPS 域名 |

微信环境由 `uni.getAccountInfoSync().miniProgram.envVersion` 判断；识别失败直接提示配置错误，不默认连开发服务器。体验版与正式版未配置时不会发送请求或上传图片。

## 手机上的 localhost

localhost / 127.0.0.1 指向运行程序的设备。开发者工具运行在电脑上，所以能访问本机后端；手机里则指向手机自身。

开发版真机调试需要手机可访问的后端地址。开发版根据 `uni.getDeviceInfo().platform` 自动区分开发者工具与手机。例如将 `weixinDevice` 改为电脑当前的局域网地址，手机与电脑在同一网络，并确认后端监听、防火墙和调试网络策略允许访问；不要把电脑IP当作正式环境域名。

正式体验与发布需要部署后端、配置 HTTPS，并在微信公众平台配置请求、上传、下载等所需合法域名。当前课程没有部署公网服务器，没有完成真机或发布验收。

## 建议验收顺序

首页商品分页与关键词搜索 → 点击商品进入详情 → 注册/登录 → 我的发布/收藏列表 → 商品留言列表 → 退出。

现有Token在内存中，重新编译或重启小程序后需要重新登录；已保存的待确认留言草稿可在原账号登录后恢复。测试发表、收藏或编辑会修改真实业务数据，测试时使用已有测试商品，完成后清理自己的测试操作。

## 第30课：开发连接诊断

开发环境首页有“开发连接诊断”入口。点击“开始检查”后并行请求 `/api/health/liveness` 和 `/api/health/readiness`，每项最多等待5秒。两项UP表示应用存活且数据库就绪；存活UP、就绪503表示服务尚未就绪，需检查数据库和日志；超时本身不能证明后端未启动。

该页面只用于开发调试，Web生产构建与微信体验版/正式版关闭诊断。请求不携带登录Token。它不会修改商品、收藏或留言。后端采用Spring Boot Actuator，两个探针只返回status，根健康接口还包含探针组名称，禁用缓存。

第42课检查时电脑en0地址是192.168.1.100。此地址只适用于当前可互通局域网；校园Wi-Fi可能隔离设备。本课按用户选择仅验收电脑、浏览器和微信模拟器，未进行手机实测，不改变系统防火墙或网络设置。
