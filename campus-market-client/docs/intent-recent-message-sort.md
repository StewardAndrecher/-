# 第65课：最近收到留言的意向优先

本课无新增依赖、无数据库迁移。只读查询，不自动标记已读。

GET /api/purchase-intents/mine 新增 sort=NEWEST（默认）或 RECENT_MESSAGE，响应回显 sort。
NEWEST 按意向创建时间、编号倒序；RECENT_MESSAGE 取当前账号在每个意向中收到的、未撤回留言的 MAX(created_at) 倒序。没有这类留言的意向在后。时间相同或都没有留言时按意向创建时间、编号倒序，确保数据不变时分页顺序稳定。

已读的留言也参与最近收到排序；标记已读只影响未读计数和未读筛选。自己发送、已撤回的留言不参与；最新留言撤回后使用剩余的最近时间。切换买方/卖方以当前账号收到的留言为准，不使用对方已读游标。

后端先鉴权、解析枚举、过滤、排序，再 LIMIT/OFFSET，不在前端对单页重排。状态与未读条件可组合；状态汇总与身份未读总览不受排序影响。SQL 排序片段来自服务端枚举，账号值使用占位符，拒绝未知排序。单次分页接口在 REPEATABLE_READ 中取得一致快照；不同分页请求之间有新留言或撤回时，顺序可变化，使用刷新取得最新结果，本课未实现跨请求快照或游标分页。

前端切换排序回第一页，翻页/刷新/身份/状态/未读条件变化和接受/取消后刷新保留排序。列表、当前页未读和身份总览全部查询成功后一起提交界面；失败保留旧顺序与旧数据并提示刷新。账号切换清空排序、列表及统计；隐藏/卸载使旧响应失效。默认 NEWEST 兼容旧服务省略 sort，主动选择 RECENT_MESSAGE 必须得到对应回显。

验收：旧意向收到新消息能跨页升到第一条；自己的消息不提升；撤回会回退；标记已读不改顺序；两端身份隔离；状态与未读组合、稳定平局、非法排序、无越权、no-store；浏览器切换与分页、失败保留/异步失效。相关子查询避免将多条留言连接成重复意向；现有 intent_id 索引支持按意向查找，但本课未做大数据量性能基准测试。
