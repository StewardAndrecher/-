# 第125课：收藏夹标题搜索

不新增软件包。复用本人收藏接口、Vue/uni-app、createFavoriteInbox状态控制器。

页面输入是待提交草稿；点击“搜索收藏”或键盘搜索才发请求。“当前关键词”展示已经提交的查询。搜索会回到第一页，刷新/翻页/可用性切换/取消后的刷新保留关键词；清空搜索保留可用性。

GET /api/favorites 增加可选keyword，首尾空白处理后最多50个UTF-16代码单元，拒绝控制字符。空关键词不传，兼容原查询。服务端先搜索当前账号可查看商品的标题，再统计分页；不是仅筛选当前5条。比较规则由数据库决定。

标题搜索只匹配当前可查看商品，失效商品不参与搜索，页面已明确提示。选择“已失效商品”且关键词非空时为空交集；清空搜索可查看失效编号。控制器拒绝非空搜索回包中出现product:null，避免误渲染不符合约定的结果。

取消收藏只操作用户明确点击的编号，写后重新查询同一条件；最后页减少最多回退一次。批量管理仍打开独立的全部收藏页；旧收藏导入仍使用原明确编号，均不随标题关键词扩展写入范围。

隐藏、卸载、换账号或同账号换token均清空搜索及输入草稿；旧异步回包不覆盖新条件。查询失败保留已提交条件并清空旧结果；取消/导入结果未知时保留条件供手动刷新核对，禁止自动重发写请求。
