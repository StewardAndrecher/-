# 我的发布：标题搜索与状态组合

GET /api/products/mine?page=1&size=5&status=ON_SALE&keyword=教材

- keyword 可选，去除首尾空白后最多50个Java/JavaScript字符单位。仅搜索当前登录卖家的商品标题，使用数据库原有排序规则做包含匹配。
- status 与 keyword 同时约束总数和分页；按商品ID降序。空关键词返回该状态下全部商品；旧接口不传关键词仍兼容。
- `%`、`_`、`!` 作为普通文字查找，使用参数绑定和 LIKE ESCAPE；不搜索描述，也不接收客户端指定卖家身份。
- 输入框是草稿，点击搜索或键盘搜索才提交；翻页、刷新、切换状态沿用已成功提交的关键词。清空搜索保留状态并回第一页。
- 加载失败保留原列表和已生效条件，保留输入草稿方便重试。账号切换清空草稿和已生效条件；旧响应不能覆盖新账号。
- 在筛选列表中改变状态后，沿用关键词补齐/纠正分页；写操作结果不确定时继续要求先GET刷新，不自动重试写请求。
- 本课没有新增依赖和数据库迁移。包含匹配未新增索引；小数据量先保证正确性，不能声称使用普通B-tree索引优化任意子串搜索。
