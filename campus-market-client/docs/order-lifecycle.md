# 第70课：模拟付款与订单超时

订单列表沿用我买到/我卖出两个角色；详情新增付款截止时间、模拟付款与超时关闭信息。PAID显示“已模拟付款（待交付）”，CLOSED_TIMEOUT显示“超时关闭”。只有买家待付款时可以模拟付款，确认框显示快照金额，并说明不会扣款。

模拟付款POST /api/orders/{id}/simulate-payment，无金额或身份请求体，沿用认证请求封装。响应只接受同一订单、状态PAID、paymentKind=SIMULATED；后端超时409后清掉旧详情并提示重新加载，不能自动创建新订单。取消响应允许CANCELLED或CLOSED_TIMEOUT，到期后的取消以服务器返回的最终状态为准。

utils/order.js校验四种状态、截止/付款/关闭时间与SIMULATED类型。时间按服务端DATETIME字符串验证与展示，不使用手机/电脑当前时间决定付款资格。主页面与新详情页保留隐藏、卸载、账号切换的过期响应保护；模拟付款/取消/读取共用互斥状态。

下单时商品保留15分钟，后台通常每批结束后30秒扫描，最多100笔；刷新订单查看最终状态。模拟付款后商品已售出，公开详情按原有规则不可见，订单参与者仍可查看订单快照。第71课已加入交付与收货，详见[order-fulfillment.md](order-fulfillment.md)；真实支付与退款尚未实现。
