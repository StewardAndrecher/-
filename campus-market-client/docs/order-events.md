# 第73课：订单进度时间线

没有新增 npm 软件包或页面。新增 utils/order-timeline.js，修改 api/order.js 和 pages/order/detail.vue。

详情首次读取使用 getOrderTimeline，一次接收订单与记录，成功后一起显示；校验序号连续、动作唯一、角色与参与者匹配、状态链、时间先后及最终状态。历史快照明确提示不能还原之前实际操作人。

操作成功后先保留服务器已确认订单，再读取新时间线。读取失败显示“操作已成功，但进度记录读取失败”，不重复提交写请求；允许新读取状态已被另一端推进，但拒绝状态倒退或快照变化。操作结果未知时按原逻辑重新读取确认。账号切换、页面隐藏/销毁及过期异步响应不能带回上一用户订单/记录。

同一 uni-app 页面供网页、微信小程序、App 资源和 Electron 内嵌网页使用。App 资源编译不代表 APK/IPA 打包或手机验收。
