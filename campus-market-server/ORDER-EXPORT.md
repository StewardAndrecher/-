# 第112课：个人订单导出

无新依赖、表、索引、迁移、权限或MQ资源。新增只读GET /api/orders/export与uni-app订单导出页。

## 查询及权限

role默认BUYER，允许BUYER/SELLER；status默认ALL，六状态与原订单列表一致。orderId缺省/空不限，非空为规范正整数字符串，上限9007199254740991。复用原编号和角色/状态校验，身份始终取登录会话；userId/limit/page不能扩大权限或上限。

后端在相同本人范围和条件下，单条参数化SQL按created_at DESC,id DESC取最多201条。最多200笔返回完整结果，201条说明超限，返回413 ORDER_EXPORT_LIMIT且不含部分records。不是只导出当前页，不静默截断，不先在前端分页拼接，避免跨页状态变化。单条SELECT使用数据库同一语句快照，不承诺跨请求冻结。

响应只含role/status/orderId/total/limit/records；每条只有id、productTitleSnapshot、priceInCentsSnapshot、status、createdAt。无对方账号/昵称、商品描述、评价、反馈、令牌或请求键。当前商品修改不改变订单快照。匿名/失效会话401，他人和不存在编号均200空记录。全部响应no-store，不写业务、关闭超时订单、共享Redis缓存或发MQ。

## 预览与导出

我的订单入口携带已提交条件及实际页码，草稿不影响导出。用户明确点击生成后才查询，重新生成先清除旧结果；失败不会留下可导出的旧快照。预览显示前10笔，CSV包含本次全部记录，空记录生成表头。可返回原列表继续缩小筛选。

网页和Mac提供本地Blob下载；微信小程序和App提供复制CSV，无服务器文件、无临时下载URL、无自动外发。网页不承诺浏览器已保存：提示发起下载并让用户确认目录。下载失败可复制。App/微信只有编译验收时，不声称原生运行或原生文件保存。

CSV使用UTF-8 BOM、CRLF、全部单元格双引号、内部双引号翻倍。金额从整数分格式化。订单号统一加可见“订单：”前缀，保留16位编号；标题统一加可见“商品：”前缀，阻止原始=、+、-、@、全角变体或前导空白成为单元格起始公式。原始标题在JSON和预览中不变。这是供人阅读的模拟交易快照，不是机器回导格式或真实收支凭证。

OWASP说明不可信CSV单元格可能被表格解析为公式，而且不存在适合所有表格和后续处理的通用转义。本课使用可见文本前缀配合CSV字段转义，不依赖隐藏字符；用户主动删除前缀、转换格式或二次导入后须自行重新核对：[OWASP CSV Injection](https://github.com/OWASP/www-community/blob/master/pages/attacks/CSV_Injection.md)。

前端严格验证字段白名单、筛选回显、200上限、行数、唯一编号、排序、状态交集、标题、时间及金额。账号/令牌变化、隐藏/卸载均清除预览并使在途请求失效。导出不持久化私人预览；用户已经下载或复制的副本不会随退出撤销，页面明确说明自行保管。
