# 第111课：个人订单精确检索与返回条件恢复

GET /api/orders新增可选orderId，缺省或空文本不限，非空为1至9007199254740991规范正整数文本，拒绝空格、前导零、正负号、指数、小数、全角数字和超范围。身份只来自当前会话；role/status/orderId在SQL取交集，查询他人和不存在订单均200空列表，不泄露是否存在。

响应orderId为数字或null；total/items只对应筛选结果，summary仍是本人当前角色的全部订单，页面明确区分。统计、COUNT和分页共享只读REPEATABLE_READ快照；SQL绑定参数、先过滤后分页；编号筛选最多1条。旧服务重载、无编号请求、交易待办入口和原状态过滤兼容。

前端输入草稿与已查询条件分离；非法编号不发请求并保留明确的上次结果范围。切角色/状态保留已查询编号，查询或清除回第一页；隐藏或身份变化清私有记录，跨账号清除旧编号。精确核对回显、结果编号、筛选总数与全量统计关系。

详情链接增加fromRole/fromStatus/fromOrderId/fromPage，均经白名单验证，不接收任意returnUrl；非空返回订单条件须匹配详情id。fromPage取服务端实际页码，返回时重新查询并允许页码收缩。旧的直接详情链接仍可使用，默认按当前参与角色进入列表。合法筛选不是权限，详情和列表均重新鉴权。

无新增依赖、表、索引、迁移、MQ资源或任务，不修改真实交易、图片、配置及权限。写入测试仅在私有临时库；资源编译不代替手机运行验收。
